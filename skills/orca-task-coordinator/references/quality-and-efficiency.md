# Autonomous Execution and Quality Ownership

## Establish boundaries before launch

Split by independent goals. Supply the complete problem, existing authorization, and shared-file/resource ownership. Order actual dependencies before startup. Group PRs by independent review, deployment, and rollback, not merely to save CI time. Keep existing merge protections.

Give Poteto original tasks and necessary context. Do not add implementation choices, test matrices, acceptance stages, or subagent rosters. Launcher checks establish startup, not product acceptance.

## Execution belongs to Poteto

Poteto owns investigation, design, internal agents, independent review, tests, verification, CI repair, and evidence under its current rules. The outer coordinator observes without freezing source, changing design, narrowing investigation, nudging, inserting reviewers, or rejecting missing steps. Answer only an explicit question, then return to monitoring.

Slow progress, shared impact, implementation differences, test failures, and red CI are reportable facts, not permission to regain control under a quality pretext.

## Receive results honestly

Summarize delivered scope, PR/commit, verification claims, failures, and limitations. Do not reread every screenshot, audit the internal process, repeat tests, or arrange another acceptance round. Report missing evidence without proactively demanding rework.

An executor report is not outer independent verification. Success at an old SHA does not prove the current SHA passed. Never rewrite evidence, hide failure, or weaken CI/merge protections. Merges and deployments still follow specific user authorization and existing release rules; this skill adds neither permissions nor new gates.

## Data and resources

Retain only necessary redacted state and identifiers, not passwords, cookies, tokens, real user records, or sensitive raw logs. Monitoring performs no data writes or resource cleanup. Separately authorized actions target exact task-owned paths/PIDs/IDs; never perform global Git maintenance or touch unrelated resources.
